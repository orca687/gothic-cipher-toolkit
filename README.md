# Gothic Cipher Toolkit

A gothic-themed Python desktop toolkit for Vigenère cipher, text encoding and decoding, and hash generation.

## 📥 Download

**[⬇️ Download Gothic Cipher Toolkit v1.0.0 for Windows](https://github.com/orca687/gothic-cipher-toolkit/releases/download/v1.0.0/Gothic.Cipher.Toolkit.exe)**

Download the executable and run it on Windows. A separate Python installation should not be required.

## Features

- Vigenère Cipher — encode and decode text.
- Text Encoding and Decoding — Base64, Hexadecimal, Binary, Octal, Unicode Escape, Quoted-Printable, and ASCII code points.
- Hash Generator — SHA-256, SHA-512, SHA-1, MD5, and combined hash options.
